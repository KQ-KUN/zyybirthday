# 地图相册

网站：https://kq-kun.github.io/mothers-memory-map-site/

本公开仓库同时保存源码、测试、加密打包工具和 GitHub Pages 发布文件。地点与生日卡片在 `album.enc.json` 中加密保存，照片在 `sealed/` 中逐张独立加密；实际姓名、生日、密钥和原始照片不提交。解锁信息只在浏览器本地使用，刷新后需要重新输入。姓名和生日可能被猜中，该方式不等同于服务端访问控制。

## 本地运行

```powershell
node --test tools/*.test.mjs
python -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。解锁清单约 6 KB，直接随 HTML 提供；解锁无需额外下载。照片按需读取与解密，失败自动重试一次。中国地理底图及周边陆地轮廓随网页提供，不使用远程瓦片、字体或图标服务。原生三维纸地图先显示，MapLibre 加载后使用相同本地数据增强；引擎不可用时地图仍可拖动、缩放和切换视角。地理数据来源见 `assets/map-sources.md`。

界面采用照片地图与编辑式排版。切换地区时，先准备并解码目标照片，再交叉淡入；连续点击只提交最新选择。地图镜头从当前帧继续，三维引擎就绪时接续原生地图视角，避免重新定位。系统开启“减少动态效果”时停用相机位移动画，保留短暂淡入。

## 更新照片

原始相册保存在仓库外，格式沿用原地图相册的 `album.json`、JPEG 照片和 `assets/credits.json`。

```powershell
node tools/encrypt-album.mjs /path/to/plain-album album.enc.json
```

脚本从隐藏标准输入接收 `{name,birthday}`，只写出密文并更新 HTML 内嵌清单。请勿将真实解锁信息写入命令、脚本或文件。每次照片更新生成新的随机文件名以避免旧缓存。推送到 `main` 后，Pages 从根目录发布。

目前为六张公共风景示例；作者和许可记录保存在加密包内，解锁后可从“照片来源”查看。尚未加入家庭照片。
