# 地图相册

网站：https://kq-kun.github.io/mothers-memory-map-site/

本公开仓库同时保存源码、测试、加密打包工具和 GitHub Pages 发布文件。地点与生日卡片在 `album.enc.json` 中加密保存，照片在 `sealed/` 中逐张独立加密；实际姓名、生日、密钥和原始照片不提交。解锁信息只在浏览器本地使用，刷新后需要重新输入。姓名和生日可能被猜中，该方式不等同于服务端访问控制。

## 本地运行

```powershell
node --test tools/*.test.mjs
python -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。解锁清单约 62 KB，直接随 HTML 提供；解锁无需额外下载。照片按需读取与解密，失败自动重试一次。中国地理底图及周边陆地轮廓随网页提供，不使用远程瓦片、字体或图标服务。原生 SVG 地图先显示，MapLibre 加载后使用相同本地数据增强；引擎不可用时地图仍可拖动、缩放和切换视角。地理数据来源见 `assets/map-sources.md`。

界面以地图为主，采用奶油色入口、深绿照片卡片和省、市、区县地理底图。切换地区时镜头连续移动，照片准备好后淡入；连续点击只提交最新选择。系统开启“减少动态效果”时使用较轻的平移，用户可用“平滑／静止”开关完全关闭移镜。地图引擎等待当前移镜结束后再接续视角，导览不会自动弹出照片遮挡地图。

手机端点击大头钉后移到近景，底部直接显示该地点照片；左右滑动或使用箭头切图。点击照片直接全屏查看，大图占满视口并支持滑动；关闭后回到同一张照片。照片按地点归组，一个地点可包含多张照片。每处地点保留独立小钉；密集标记只在屏幕上错位，并以细线连接原始位置，不改变地理坐标。名称放在钉子左侧，放大后显示。地图默认 2D、平滑移动，底部只保留全部照片和按地区浏览。

为 200 多张照片准备了离屏加载、离屏移除图片、两张并发下载及近期照片缓存回收。缓存目标为 12 张、32 MiB 加密前 JPEG 数据；显示中或解码中的照片受到保护，预算可暂时超出。该预算不代表浏览器总内存。加密工具逐张读取照片，避免将全部原图同时读入内存。正式导入手机照片前，应生成保留方向、最长边约 1600–2000 像素的网页副本，并保留原图在仓库外。

## 更新照片

原始相册保存在仓库外，格式沿用原地图相册的 `album.json`、JPEG 照片和 `assets/credits.json`。

```powershell
node tools/encrypt-album.mjs /path/to/plain-album album.enc.json
```

脚本从隐藏标准输入接收 `{name,birthday}`，只写出密文并更新 HTML 内嵌清单。请勿将真实解锁信息写入命令、脚本或文件。每次照片更新生成新的随机文件名以避免旧缓存。推送到 `main` 后，Pages 从根目录发布。

当前包含 124 张照片，归入 60 个地点；照片及缩略图均独立加密。源文件及地点核对表保存在仓库外。HEIC 已转换为 JPEG，网页副本最长边 2000 像素，缩略图最长边 480 像素，副本已移除 EXIF 拍摄位置。
