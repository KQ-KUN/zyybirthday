# 地图相册

网站：https://kq-kun.github.io/mothers-memory-map-site/

本公开仓库同时保存源码、测试、加密打包工具和 GitHub Pages 发布文件。地点与生日卡片在 `album.enc.json` 中加密保存，照片在 `sealed/` 中逐张独立加密；实际姓名、生日、密钥和原始照片不提交。首次解锁后，在当前浏览器记住设备解锁密钥，不保存姓名和生日明文。优先将不可导出的 CryptoKey 保存到 IndexedDB；不支持时将设备解锁凭据保存到 localStorage，再次读取时导入不可导出的密钥。使用该浏览器的人可以直接打开相册；“＋ → 忘记本机解锁”可取消。清除站点数据、无痕模式、换浏览器或独立桌面应用的存储隔离可能需要重新输入一次。姓名和生日可能被猜中，该方式不等同于服务端访问控制。

## 本地运行

```powershell
node --test tools/*.test.mjs
python -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。解锁清单约 62 KB，直接随 HTML 提供；解锁无需额外下载。照片按需读取与解密，失败自动重试一次。中国地理底图及周边陆地轮廓随网页提供，不使用远程瓦片、字体或图标服务。原生 SVG 地图先显示，MapLibre 加载后使用相同本地数据增强；引擎不可用时地图仍可拖动、缩放和切换视角。地理数据来源见 `assets/map-sources.md`。

界面以地图为主，采用奶油色入口、深绿照片卡片和省、市、区县地理底图。切换地区只连续平移，保持当前近景高度和斜角，不使用先升高拉远的飞行曲线；照片准备好后淡入；连续点击只提交最新选择。系统开启“减少动态效果”时使用较轻的平移，用户可用“平滑／静止”开关完全关闭移镜。地图引擎等待当前移镜结束后再接续视角，导览不会自动弹出照片遮挡地图。

手机端点击大头钉后平滑移到 62° 倾斜近景，保持贴近地面的斜视角，底部直接显示该地点照片；左右滑动或使用箭头切图。点击照片直接全屏查看，大图占满视口并支持滑动；关闭后回到同一张照片。退出大图、照片列表或地点卡片时，地图在当前位置平滑恢复 2D；重新点击地点才再次切入斜视近景。系统返回、浏览器后退和关闭按钮按“大图 → 地点卡片 → 地图”逐层返回；从照片列表打开时先返回原列表。切换照片只更新当前记录，前进可恢复上次照片；地图主界面保留正常离站行为。照片按地点归组，一个地点可包含多张照片。每处地点保留独立小钉；密集标记只在屏幕上错位，并以细线连接原始位置，不改变地理坐标。名称会在上下左右及斜向寻找空位，避开其他地图钉、名称和视口边缘；放大后显示。地图默认 2D、平滑移动，底部提供全部照片、按地区浏览和一键浏览。

每次解锁后播放照片拼字开场：从相册均匀选取八张缩略图，拼成两行“生日快乐”。字形使用站酷快乐体的四个固定矢量轮廓，不依赖手机字体，也不会回退宋体；许可见 `assets/birthday-lettering-license.txt`。照片完成拼字后保持停留，不再自动进入地图，点击右上角“×”关闭。减少动态效果时只保留淡入。开场关闭后再启动地图增强引擎。生日日期只从加密内容读取。

为 200 多张照片准备了离屏加载、离屏移除图片、两张并发下载及近期照片缓存回收。缓存目标为 12 张、32 MiB 加密前 JPEG 数据；显示中或解码中的照片受到保护，预算可暂时超出。该预算不代表浏览器总内存。加密工具逐张读取照片，避免将全部原图同时读入内存。正式导入手机照片前，应生成保留方向、最长边约 1600–2000 像素的网页副本，并保留原图在仓库外。

## 更新照片

原始相册保存在仓库外，格式沿用原地图相册的 `album.json`、JPEG 照片和 `assets/credits.json`。

```powershell
node tools/encrypt-album.mjs /path/to/plain-album album.enc.json
```

脚本从隐藏标准输入接收 `{name,birthday}`，只写出密文并更新 HTML 内嵌清单。请勿将真实解锁信息写入命令、脚本或文件。每次照片更新生成新的随机文件名以避免旧缓存。推送到 `main` 后，Pages 从根目录发布。

当前包含 124 张照片，归入 60 个地点；照片及缩略图均独立加密。源文件及地点核对表保存在仓库外。HEIC 已转换为 JPEG，网页副本最长边 2000 像素，缩略图最长边 480 像素，副本已移除 EXIF 拍摄位置。

## 本机添加照片与备份

右上角“＋”打开添加入口。每次可选 1–20 张图片，填写地点名称，再直接输入城市、区县或景点名称搜索，点击匹配结果选取大致位置；不再使用下拉选择框。全国城市、现有区县以及相册景点随网页提供，搜索不发送到第三方。保存后立即更新地图钉；选已有地点并沿用名称时合入同一个钉子。浏览器将图片转成最长边 2000 像素的 JPEG 和 480 像素缩略图，并分别加密。HEIC 能否直接读取取决于浏览器，不支持时会提示转换为 JPG。

新增照片和地点保存在当前浏览器的 IndexedDB，不上传到 GitHub或云端。解锁后才能读取，刷新仍保留；清除站点数据、浏览器回收空间、换浏览器或换手机可能无法继续读取，必须提前导出备份。持久存储请求可能被浏览器拒绝。单个相册的本机新增内容限制为 150 MiB，导出的 `.mapalbum` 包含本机新增内容和地图钉移除设置，采用同一相册密钥加密。导入会先验证所有照片再以事务保存；重复导入不新增同名编号，校验失败不写入，保留原有照片。新旧版本更新须保留原相册 salt，以继续读取本机内容与备份。

本机存储接口在 `local-album.js`：`createLocalAlbum({key, namespace})`，`load()` 返回新增地点，`add(place, images)` 事务保存加密图片与地点，`readPhoto(photo)` 读取密文，`exportBackup()` 返回 Blob，`importBackup(blob)` 校验并合并备份。该接口不提供跨设备同步；未来如需云端，可另接存储适配层，不能在静态前端放 GitHub 凭据。

点击地点卡片右下角垃圾桶可删除地图钉。确认界面会显示地点名称和后果：只从当前浏览器的地图移除，照片保留，不修改 GitHub 原始相册。移除状态加密保存，刷新后保留；“＋ → 已移除的地点”可以恢复。所有原有和本机新增地点都支持此操作。本机元数据从旧版数组格式兼容迁移到含 `places`、`hiddenIds` 的结构，旧照片与旧备份仍可读取。存储接口新增 `hiddenIds()` 和 `setHidden(id, hidden)`。

## 照片传输与自动浏览

照片优先读取已认证的本机密文缓存；网络请求依次启用 Pages、jsDelivr、GitHub Raw 三条线路，备用请求延迟启动，首个通过 AES-GCM 认证的结果获胜，取消其余请求。三者均托管相同密文，不传输解锁信息。缓存预算 128 MiB；优先 IndexedDB，不支持时使用 Cache Storage。前台使用缩略图先显示再切高清，离屏项取消排队、显示项持有租约，失败可重试。后台在空闲时逐张缓存原始相册缩略图。未加载过的照片仍依赖网络，不能保证任何网络环境都能访问。

拼字内的照片格可点击打开；下方履带收录当前相册全部照片，使用两份相同的照片序列向左无缝循环，约每 2.5 秒移动一张的宽度。只加载视口附近的缩略图，离屏后释放租约。点击任意照片可打开大图，关闭或返回后仍停留在生日祝福，右上角 × 才进入地图。履带提供播放/暂停按钮；键盘聚焦照片、打开大图时暂停，系统减少动效时默认暂停，仍可主动播放。

底部三个入口同排，一键浏览采用金色实底提高对比度。照片切换保留不透明旧图，新图解码后覆盖淡入；同张照片的缩略图换高清不再重复淡入。快速切换时保留当前混合画面，等新图准备好再接续，退出后释放图层和照片租约。右上角首页按钮停止自动浏览、收起地点卡片并平滑回到 2D 地图总览，不清除本机解锁或照片。

底部“一键浏览”循环浏览地点：首图可见后计时，每个地点停留 5 秒，多图地点每 2 秒切换一张。一次停留最多显示三张，下一轮从该地点尚未显示的照片继续。手动选择地点、切图、打开大图或其他弹窗、浏览器返回、切到后台时暂停；可再次点击继续。

Service Worker 缓存网页、地图引擎与本地地理数据，照片缓存单独保存密文。离线只能读取已经缓存的内容。修改发布版本或脚本文件列表后运行 `npm run build`，CI 会检查生成文件；新版本安装成功后才回收旧网页缓存，不触碰本机上传照片和解锁记录。
